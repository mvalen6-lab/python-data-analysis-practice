# Student Grade Analysis

This beginner-friendly project analyzes a small student grades dataset using Python.

## Project Goal

The goal of this project is to practice basic data analysis skills by calculating averages, identifying performance trends, and summarizing student results.

## Tools Used

- Python
- CSV files
- Basic data analysis

## What This Project Shows

- How to organize data in a CSV file
- How to calculate averages
- How to summarize information clearly
- How to communicate simple data insights
