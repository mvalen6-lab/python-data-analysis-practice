# Student Performance Analysis Using Python
This beginner-friendly project analyzes a small student grades dataset using Python.

## Project Goal

The goal of this project is to practice basic data analysis skills by calculating averages, identifying performance trends, and summarizing student results.

## Tools Used

- Python
- CSV files
- Basic data analysis

## What This Project Shows

- How to organize data in a CSV file
- How to calculate averages
- How to summarize information clearly
- How to communicate simple data insights

## Results

This project calculates:

- Overall class average
- Average grade by course
- Average grade by student
- Highest and lowest grade
- Basic insights from the dataset

## Key Insights

Based on the sample dataset:

- The overall class average is calculated from all student grades.
- The project compares performance between Math and English.
- The analysis identifies the top-performing student and the student with the lowest average.
- The project demonstrates how Python can be used to summarize simple academic data.

- ## Skills Practiced

- Reading CSV files with Python
- Organizing data using dictionaries and lists
- Calculating averages
- Comparing grouped data
- Writing clear project documentation
- Communicating simple data insights
